## Use context for owned values

```tsx
const Theme = createContext('light')

function Label() {
  const theme = useContext(Theme)
  return <span data-theme={theme}>Current theme: {theme}</span>
}

<Theme.Provider value="dark"><Label /></Theme.Provider>
```

Context follows logical ownership through branches, lists, nested components, portals, server rendering, and hydration.

## Subscribe to external state

```tsx
const value = useSyncExternalStore(
  store.subscribe,
  store.getSnapshot,
  store.getServerSnapshot,
)
```

- Return a stable snapshot while the store has not changed.
- Return an unsubscribe function from `subscribe`.
- Supply a server snapshot for matching SSR and hydration.
- Use an external store when state must survive root replacement or HMR.
