## Name route files

| File | Matched path |
| --- | --- |
| `src/routes/index.tsx` | `/` |
| `src/routes/products.tsx` | `/products` layout |
| `src/routes/products/$productId.tsx` | `/products/:productId` |
| `src/routes/docs/$.tsx` | `/docs/*` catch-all |

Render a layout's `children` where the selected descendant should appear.

## Load data from the server

```tsx
const loader = async ({ params, request, parentData }: RouteLoaderContext) => ({
  product: await findProduct(params.productId),
  requestedFrom: new URL(request.url).pathname,
  parentData,
})
```

Matched loaders run from parent to child. Their results must fit the framework serializable value model.

## Return an endpoint response

```tsx
export const Route = defineFileRoute({
  server: {
    handlers: {
      GET: () => Response.json({ now: new Date().toISOString() }),
    },
  },
})
```

## Navigate programmatically

```ts
const client = await hydrateStart({ manifest: routeManifest })
await client.navigate('/products/42')
await client.navigate('/login', { replace: true, scroll: false })
```
