## Choose a stable key

```tsx
<ul>
  {todos.map((todo) => (
    <li key={todo.id}>{todo.title}</li>
  ))}
</ul>
```

Use a primitive identity that belongs to the record. Vidact associates each owned DOM range with that logical item across insertions, removals, and moves.

> [!WARNING] Keys must be unique
>
> A duplicate key fails before Vidact changes the current DOM order. Avoid changing labels, array positions, or freshly generated values.

## Use index identity deliberately

An unkeyed array can use position when records never reorder and state does not belong to an individual record. Prefer stable keys for interactive collections.
