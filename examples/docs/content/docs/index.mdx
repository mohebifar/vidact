## What is Vidact?

Vidact is an experimental compiler for React-shaped TypeScript and JSX. It turns supported function components into direct DOM construction and compiler-selected updates. Components construct once when mounted; state changes update only the DOM, child props, ranges, and effects that read the changed value.

> [!WARNING] Experimental software
>
> Vidact is currently published as a beta. Test production applications against the exact compiler and runtime versions you ship.

## The core contract

| Property | Vidact behavior |
| --- | --- |
| Rendering | Direct DOM construction without a Virtual DOM |
| Updates | Static compiler-selected operations |
| Components | Supported functions construct once per mount |
| React | Source compatibility for a documented subset; no runtime fallback |
| Failure mode | Unsupported patterns are diagnosed during compilation |
