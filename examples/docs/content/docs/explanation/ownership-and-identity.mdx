## Every dynamic region has an owner

Vidact assigns lifetime to roots, components, conditional ranges, and list records. Owners retain nodes while valid and dispose nested bindings, refs, subscriptions, effects, and child owners when removed.

## Identity decides what survives

| Region | Identity source |
| --- | --- |
| Root | Mounted compiled application owner |
| Component | Construction site and surrounding owner |
| Conditional branch | Selected owned range |
| Keyed list record | Stable primitive key |
| Indexed list record | Position |
| Portal | Logical owner with a physical target |

Stable identity preserves DOM, focus, selection, and owned state. Changed identity disposes the previous owner before installing the next one.
