## The server constructs deterministic output

The server target executes component construction without browser globals, escapes text and attributes, and writes markers for dynamic ownership. It does not create browser DOM or run client effects.

## Hydration claims existing ownership

The hydrate target follows the same component and range structure, claims nodes, installs bindings and listeners, and reports recoverable mismatches. Server and hydration must agree on protocol, features, and initial data.

## Vidact Start transfers route data

Start serializes loader results into a closed framework snapshot. Hydration resolves the same route chain with that data so browser construction observes the values used by the server.
