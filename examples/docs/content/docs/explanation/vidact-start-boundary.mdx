## Start owns the request lifecycle

| Layer | Responsibility |
| --- | --- |
| Vite plugin | Discover files and generate a route manifest |
| Start server | Match requests, run loaders, create snapshots |
| Vidact server runtime | Render route components |
| Start client | Hydrate, fetch snapshots, manage history |
| Vidact client runtime | Own and replace the route root |

## The first boundary is intentionally narrow

The first release chooses complete route-root replacement over retained layout reconciliation. It includes file routes, nested layouts, loaders, endpoints, SSR, hydration, links, programmatic navigation, and history restoration while leaving middleware, preloading, and deployment adapters for later contracts.
