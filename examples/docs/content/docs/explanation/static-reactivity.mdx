## State slots are explicit sources

A compiler-lowered state slot contains an ordinary value and stable dispatcher. A write marks a compiler-assigned source dirty; it does not enqueue a component render.

## Static masks select updater work

The compiler records which values each derivation and observable operation reads and writes. Source masks select affected operations in compiler-defined order. Batching runs each affected updater once per flush.

| Question | Vidact answer |
| --- | --- |
| Who discovers dependencies? | The compiler |
| When is a component called? | Once for each mount |
| What runs after a write? | Selected derivations and observable updaters |
| How are cycles handled? | Ambiguous or non-stabilizing flows fail loudly |
